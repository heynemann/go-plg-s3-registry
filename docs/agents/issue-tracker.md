# Issue tracker: GitHub

Specs and tickets live in [heynemann/go-plg-s3-registry](https://github.com/heynemann/go-plg-s3-registry/issues). Use `gh` to create, read, list and update issues. Target this repository explicitly when running from another checkout.

Use native sub-issues for parent links and native issue dependencies for blockers. A ticket is unblocked when all of its blockers are closed.

**PRs as a request surface: no.**
