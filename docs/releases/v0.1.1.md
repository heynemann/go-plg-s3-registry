# v0.1.1 — Developer preview

First published preview of `go-plg-s3-registry`, for local evaluation with Floci and synthetic data. **Not for production deployment.**

- Publish signed, immutable plugin versions. Approve exact plans, warm a candidate at 0%, advance a targeted rollout, roll back, and quarantine a digest without repinning existing work.
- Use the Go `dataplane` SDK to load exact digests, persist selection receipts in your operation store, and report adoption and invocation telemetry. There is no registry HTTP server and no change to `go-plg` core.
- Run the rewards walkthrough with two Lua releases, a real HTTP host, and a SQLite ledger to exercise retry, restart, rollback and containment.

Install with `go install github.com/heynemann/go-plg-s3-registry/cmd/plg-registry@v0.1.1`. Check out `v0.1.1` to run `./examples/rewards/run-demo.sh`. See the [README](https://github.com/heynemann/go-plg-s3-registry/blob/v0.1.1/README.md) and [compatibility policy](https://github.com/heynemann/go-plg-s3-registry/blob/v0.1.1/docs/compatibility.md).

The `v0.1.0` tag was not published as a GitHub release and is retracted. Its tagged rewards example could not warm the offline contract because of the Go build's version stamp. The corrected example still pins its fixture contract, and the release workflow installs the published CLI and runs the complete walkthrough from the tag.

Go 1.27.3 and the pinned `go-plg` revision are tested together. No cross-version or production support is implied by the preview or by version-1 storage records. Live AWS conformance remains open in [#15](https://github.com/heynemann/go-plg-s3-registry/issues/15).
