# v0.1.0 — Developer preview

First tagged release of `go-plg-s3-registry`. Intended for local evaluation with Floci and synthetic data, **not production deployment**.

- Publish signed, immutable plugin versions. Approve exact plans, warm a candidate at 0%, advance a targeted rollout, roll back, and quarantine a digest without repinning existing work.
- Integrate the Go `dataplane` SDK to load exact digests from an environment bucket, persist selection receipts in your own operation store, and report adoption and invocation telemetry. There is no registry HTTP server and no change to `go-plg` core.
- Run the rewards walkthrough to see two Lua releases, a real HTTP host, SQLite-backed deliveries, a restart, rollback, and containment.

Install with `go install github.com/heynemann/go-plg-s3-registry/cmd/plg-registry@v0.1.0`. Check out `v0.1.0` to run `./examples/rewards/run-demo.sh`. See the [README](https://github.com/heynemann/go-plg-s3-registry/blob/v0.1.0/README.md) for prerequisites and SDK setup and the [compatibility policy](https://github.com/heynemann/go-plg-s3-registry/blob/v0.1.0/docs/compatibility.md) for toolchain, stored formats and upgrades.

Go 1.27.3 and the pinned `go-plg` revision are tested together. No cross-version or production support is implied by the preview or by version-1 storage records. Live AWS conformance remains open in [#15](https://github.com/heynemann/go-plg-s3-registry/issues/15); the hosted release check installs the tagged CLI and exercises it against Floci, not AWS.
